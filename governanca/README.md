# GABA — Governança em IA e Business Analytics

Esta pasta reúne os materiais de governança do FOMEZERO.

A GABA consolida a integração das disciplinas, documenta riscos, privacidade, LGPD, qualidade de dados, indicadores e limitações do protótipo.

## Conteúdo

- `documento/`: documento ABNT/FIAP da disciplina.
- `dashboard/`: dashboard de governança e impacto.
- `evidencias/`: evidências da integração e dos indicadores.

## Limitações

- O dashboard é uma proposta extra e não substitui o vídeo, o GitHub ou o documento.
- Nenhum módulo determina automaticamente se um alimento é seguro para consumo.
- Dados pessoais reais de beneficiários não são utilizados.
- Simulações, dados físicos e propostas futuras devem permanecer separados.
