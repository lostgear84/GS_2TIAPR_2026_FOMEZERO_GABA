# CCNS — Cluster Computing, Computação Neuromórfica e Supercomputadores

Esta pasta reúne a simulação de memória resistiva realizada no Falstad.

A simulação investiga a retenção do estado resistivo de um memristor como possível contribuição conceitual à rastreabilidade de eventos térmicos no FOMEZERO.

A simulação utiliza sinal sintético. Ela não recebe dados do DHT22, mensagens MQTT ou informações do ESP32 físico. Portanto, não valida o firmware, não comprova quebra da cadeia de frio e não deve ser tratada como integração física concluída.
